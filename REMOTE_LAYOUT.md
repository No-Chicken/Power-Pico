# Repository Layout

The top-level directories follow the upstream Power-Pico repository:

- `software/Power_Pico`: firmware source and build configuration.
- `firmware`: v1.2.0 release image, upstream reference images, and Bootloader.
- `PC_Client`: upstream client installer.
- `hardware`: schematic.
- `3D models`: enclosure and button models.
- `images`: README illustrations and measurement examples.
